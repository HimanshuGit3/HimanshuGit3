## Featured Projects

### JobScamAlert — Offer Letter Inspector

Scans job-offer text and URLs for suspicious signals and explains how each signal contributes to the result.

- Combines optional Gemini fact extraction with deterministic scoring, domain-age checks, and Google Safe Browsing integration.
- Includes URL-fetch safeguards, backend/frontend tests, and GitHub Actions for linting, type checking, testing, and container builds.

**Stack:** Python · FastAPI · React · TypeScript · Gemini API · Docker

[Repository](https://github.com/HimanshuGit3/JobScamAlert) · [Browser Demo](https://himanshugit3.github.io/JobScamAlert/) · [CI Workflow](https://github.com/HimanshuGit3/JobScamAlert/blob/main/.github/workflows/ci.yml)

*The public demo runs browser-based checks. Gemini and Safe Browsing require the configured backend.*

### SEVERANCE — Local Document Trust Workbench

A hackathon prototype for document Q&A that filters retrieved passages by a user's access permissions before passing context to a local LLM.

- Implements rank-and-compartment access checks, source-citation verification, and a SHA-256 hash-chained audit ledger.
- Includes PDF ingestion, Ollama integration, a React interface, and Docker Compose configuration with internal networking and a separate code sandbox.

**Stack:** Python · FastAPI · Ollama · SQLite · React · Docker Compose

[Repository](https://github.com/HimanshuGit3/Sovereign-AgenticAI-workbench) · [API Documentation](https://github.com/HimanshuGit3/Sovereign-AgenticAI-workbench/blob/main/API.md)

### SMRITI — Drilling Knowledge & Risk Exploration

A hackathon prototype that turns offset-well reports into searchable drilling knowledge and risk views, using **synthetic data**.

- Implements PDF/OCR ingestion, formation-aware risk scoring, and question answering with source citations.
- Combines a NumPy logistic-regression model with rule-based alerts on simulated drilling data.

**Stack:** Python · FastAPI · Ollama · NumPy · SQLite · React

[Repository](https://github.com/HimanshuGit3/SMRITI_WELL) · [Architecture](https://github.com/HimanshuGit3/SMRITI_WELL/blob/main/docs/ARCHITECTURE.md) · [Data Notes](https://github.com/HimanshuGit3/SMRITI_WELL/blob/main/docs/DATA.md)

### Automatic Question Generator

An NLP prototype that converts PDFs or pasted text into multiple-choice, short-answer, descriptive, and true/false questions.

- Uses FLAN-T5 for question generation, KeyBERT for keyword extraction, and NLTK for sentence processing.
- Connects a FastAPI upload endpoint to a React/TypeScript interface with quiz functionality.

**Stack:** Python · FastAPI · Transformers · KeyBERT · NLTK · React

[Repository](https://github.com/HimanshuGit3/AutomaticQuestiongeneratornlp) · [Generation Pipeline](https://github.com/HimanshuGit3/AutomaticQuestiongeneratornlp/blob/main/backend/app.py)
